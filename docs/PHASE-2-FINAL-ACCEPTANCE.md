# 阶段二最终验收

验收日期：2026-08-28  
发布版本：0.2.0  
数据库：schema v15

## 结论

阶段二“从小说生成可审核、可追溯、按进入位置防剧透的人物关系图与世界书”的本地电脑端主流程已经跑通。关系候选不会自动升级为事实，所有正式关系仍要求已确认人物和可对齐原文证据；图形界面、历史详情、社区摘要和两个导出格式共同读取同一个进入位置投影。

## 已完成范围

- 版本化关系候选、断言、证据、有效期、来源视角、真实性、冲突和取代历史。
- 可恢复的本地/模型扫描任务与证据案卷式人工审核。
- Cytoscape.js 防剧透图谱、关系演化、最短路径、过滤、定位与大图布局降级。
- 确定性社区检测、可追溯社区摘要、`character_graph.json` 1.0。
- 当前 SillyTavern 世界书结构导出，中文整词匹配关闭，来源 ID 保存在扩展字段。
- `.novelproj` 安全恢复：拒绝路径穿越、符号链接、未知/重复条目、内容/校验清单不一致、超过 4 GB 解压上限和覆盖已有目录；校验通过后才原子落位。

## 验证证据

- TypeScript 严格类型检查通过。
- Vitest：19 个文件、51 项全部通过。
- 大文件：约 1 MB、10 MB、50 MB 的导入与重新打开全部通过；本机 50 MB 样本约 1.7 秒。
- Electron E2E：6 项通过，1 项需要真实 DeepSeek 凭据而按显式开关跳过。
- 生产构建通过；主界面约 290 KB，关系图约 458 KB 独立懒加载。
- 独立 `release-phase2-audit/win-unpacked` 打包成功，ASAR 已确认包含 `unzipper`，打包版启动和数据库服务烟雾测试通过。
- 0.1.2 三个回滚文件的字节数与 SHA-256 全部匹配原发布记录，便携目录版应用和数据库服务可启动。

## 已知发布注意事项

- 历史 0.1.2 产物内部预加载版本仍报告 0.1.1；哈希证明这是原产物遗留，不是本轮改写。它不影响启动和数据库服务，但回滚排障时应以文件哈希与发布记录识别版本。
- 单文件便携版的自解压启动器无法在 30 秒内被 Playwright Electron 驱动挂接；从同哈希发布组的便携目录 ZIP 解出的应用本体已通过烟雾验证。
- 真实 DeepSeek 三请求测试必须显式启用且会消耗用户 API 额度；本次本地验收没有自行消费外部额度。HTTP 契约、非思考参数、结构化响应和失败处理已由本地模拟 API 覆盖。
