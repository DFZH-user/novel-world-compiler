# 阶段 1B 批次 3：对白与说话人归属

## 当前能力

本批建立独立的对白数据层，不把对白内容直接混入人物事实提示词。

本地规则可以识别：

- 中文弯双引号 `“……”`；
- 中文直角引号 `「……」`；
- 中文双直角引号 `『……』`；
- ASCII 双引号 `"..."`；
- 段落行首的单/双破折号对白。

每条对白保存稳定段落 ID、段落内起止字符位置、对白原文、引号类型和识别方式。已排除段落不会参与扫描。

## 说话人候选

### 明确线索

规则检查对白前后局部文本中的人物名称、已确认别名和言说动词，例如：

- `陆沉说道：“先走。”`
- `“我随后就来。”周平答道。`

只有同时满足以下条件时才自动确认：

1. 只匹配到一个人物；
2. 人物身份已经由用户确认；
3. 姓名或确认别名与言说动词形成局部明确线索。

### 邻近上下文

没有明确线索时，系统检查对白所在段落及前后一个段落的人物提及，最多生成五个低置信候选。邻近人物永远不会自动成为已确认说话人，因为对白中提到的人、在场人物和真正说话人可能不同。

### 人工审核

- 用户可以确认、排除或恢复候选。
- 用户可以从未排除的人物中直接指定说话人。
- 确认新说话人时，旧的已确认项恢复为待审核，不物理删除。
- 人物合并会同步移动对白归属；撤销合并会恢复原人物归属。
- 按证据拆分人物时，相关对白归属恢复为待审核。

## 当前边界

- 本批扫描完全在本机执行，不调用模型 API。
- 尚未分析无引号自由间接引语。
- 已能用局部两人对话轮次生成待审核候选，但尚未使用模型处理剩余隐式说话人。
- 尚未提取受话人；数据表已经预留 `addressee` 角色。
- 已从确认对白生成基础统计画像；更高层的语气描述和角色卡语言提示仍需等样本量与归属精度达到门槛。

## 本地轮次分析

系统在用户点击“分析隐式轮次”后检查：

- 前两条已确认对白是否由两个人交替发言；
- 当前对白前后是否存在同一位已确认说话人；
- 前后两段范围内是否只有两名已确认人物；
- 候选人物是否仍是当前修订中的已确认身份。

这些规则只能生成 `turn_taking` 待审核候选，不会自动确认。重复运行是幂等的，不会生成重复候选。

## 语言画像

语言画像只读取已确认说话人的对白，统计：

- 对白数量、总字符数和平均长度；
- 疑问、感叹和省略号使用比例；
- 第一人称、句末语气词、礼貌用语和古典称谓比例；
- 高频人称、称谓和礼貌标记；
- 从全书前、中、后位置选择的短代表样本。

候选确认、排除、恢复或人工改派说话人后会立即重建画像。身份合并、拆分或撤销后会清除旧画像，避免显示过期统计。

## 后续顺序

1. 为仍未解决的对白提供可选模型分析，并保存模型理由与证据。
2. 在时间线完成后，把全书画像拆为剧情阶段画像。
3. 将语言特征接入角色卡，而不是把大段原文直接复制进卡片。
