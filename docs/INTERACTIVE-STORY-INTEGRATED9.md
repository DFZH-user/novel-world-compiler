# integrated.9 — 桌面互动小说

保留浅色阅读、小鲸鱼和文字水波。酒馆新增剧情辅助、行动合理性、剧情结算、阅读排版、人物外观。

## 使用
- 在酒馆配置聊天补全连接。辅助分析复用此连接，模型可独立指定；不使用编译器 API 密钥。
- 自动剧情结算默认开启：正文完成后额外分析，状态默认折叠，最多四种行动倾向：保护、利己、中立、角色专属。无依据时减少数量。
- 行动合理性默认开启、按会话保存。明确冲突保留草稿，可尝试或资料不足时允许明确选择按尝试发送。关闭后跳过检查并启用自由叙事提示。
- 玩家身份来自酒馆“我的身份”；玩家已知设定与能力可在行动合理性页补充。不会直接读取主角色卡的隐秘设定或未公开世界书，避免用检查泄露秘密。
- 辅助分析需要聊天补全连接；其他原生连接的正文功能保留，使用时可关闭合理性检查和自动结算。
- 本轮动作必须对应公开材料；结算状态变更仅采纳完整正文及上次有效状态的逐字证据。语义判断仍依赖模型，不等于确定性规则引擎。

## 回合与恢复
- 辅助结果写入聊天 metadata 的 novel_story 字段，包含原文历史 SHA-256、回合索引和已验证片段，不改聊天 mes。
- 编辑、删除、候选切换改变历史指纹，旧状态不再冒充有效状态。重开原会话恢复匹配记录；复制相同历史的分支可复用已有快照。
- 新生成禁用旧行动。主动停止的未完成正文不自动结算。失败保留正文、标记上一状态未更新、清空行动，可手动单独重试。
- 会话切换取消辅助请求；迟到结果也必须再次通过会话和历史一致性检查。
- 群组在整个轮次结束后结算多角色正文；不能把早到的成员回复当整轮完成。

## 阅读与素材
- 连续小说为默认；可突出明确人物对白。不确定的说话人退回普通正文；切换不修改原始文字。
- 已有代码块、HTML、图片等富内容保留原生渲染。中文缩进、Markdown外观清理仅作用于显示。
- 文字头像、当前主角色卡头像、显式关联和上传头像。上传自动中心裁剪为 256 像素；可恢复文字头像。
- 自定义头像随会话 metadata 保存。字体独立存入 IndexedDB，支持 TTF/OTF/WOFF/WOFF2，40 MB，真实加载验证后启用；不放入聊天 JSON，缺失时回退。
- 正文字号沿用现有“阅读与动效”；新增字体、宽度、行距与段距。
- 用户选择文字、编辑和正文生成时暂停动效。

## 验证
使用隔离角色和会话，所有模型请求均模拟，没有消耗用户真实 API 额度。
验收包含发送前拦截、关闭检查后的正文生成、独立结算、失败重试、历史失效、会话重开和迟到结果隔离。
