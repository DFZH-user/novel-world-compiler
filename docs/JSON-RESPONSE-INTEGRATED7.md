# integrated.7：人物普查 JSON 回复恢复

用户报告一键生成在人物普查阶段停止，界面只展示模型回复前 300 字。历史代码没有保存服务端 finish_reason，所以无法仅凭截图确认这一次是否因截断而失败。

修复：保留结束原因；检测 length/max_tokens 截断，即使剩余内容恰好可解析也不接收；兼容单个完整 JSON 外的代码围栏或说明文字；不补括号、不改写引文、不保存部分人物。

人物普查维持最多三次尝试。确认截断时下一次输出上限从 6000 提高到 12000（上限不再增加），并提示生成精简完整对象。普通格式错误维持原额度；内容过滤直接停止。额外输出只在用户运行任务并遇到截断时发生。

提示中展示结束原因、输出 token 和上限，不再把长段原始 JSON 堆到页面。已有完成分块和原文不变；更新后可使用“从失败处重试”。数据库结构未变。

验证使用本地模拟响应，包括完整 JSON、围栏、说明包装、截断、语法破损、多文档、过滤、预算上限、失败不写入及 transport 结束原因传递；未调用真实付费接口。此修复改进错误恢复，不能保证模型永远生成有效 JSON。
