# integrated.15 酒馆完整安装修复

之前的开书动画补丁安装包包含 SillyTavern 的程序文件，但打包时漏掉了 `resources/sillytavern/node_modules`，因此编译台可用、酒馆无法启动。本版将酒馆运行依赖一并封入安装版、便携版和解压版。

内部应用版本号仍为 `0.3.0-integrated.15`，本发布标签标识补齐酒馆依赖的安装修复。原小说工程和用户目录不变，无需重新编译小说或再次调用模型。

## 验证

- 解压运行版资源检查通过：酒馆核心文件及 `express`、`yaml`、`yargs`、`webpack` 均从包内路径解析。
- 隔离的《蛊真人》工程副本在解压版中完成“书库 → 阅读准备 → 选择其他时间地点 → 启动内置酒馆”的流程。
- 从最终安装版提取真实安装内容，再次通过同一完整流程。安装包内 21,138 个文件读取完整。
- 用户工程、聊天记录、密钥、备份没有进入发布包；没有付费模型调用。

## 下载

安装版文件名：`novel-world-setup-integrated15-complete-tavern-x64.exe`。便携版和解压版 ZIP 也包含完整酒馆依赖。优先下载本发布，旧的动画补丁发布包不包含酒馆依赖。
