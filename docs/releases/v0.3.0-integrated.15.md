# integrated.15 发布说明

## 本版内容

- 完整的书库、编译工作台与沉浸阅读路径。
- 独立世界书、精简运行人物卡、玩家身份与开场场景自动装配。
- 全部已确认事件的搜索选择及当时已揭示地点选择；复用既有工程数据，不重跑付费生成。
- 左侧行动建议、中间正文与输入、右侧剧情状态的可调整阅读布局。
- 人物中心关系时间线及分层示意地图。
- 北邮校内 API 展示名到准确模型 ID 的兼容修正，已失败的一键任务重试时也生效。

## 下载

- 安装版：novel-world-setup-0.3.0-integrated.15-x64.exe。
- 单文件便携版：novel-world-portable-0.3.0-integrated.15-x64.exe。
- 一次解压版：novel-world-unpacked-0.3.0-integrated.15-x64.zip。


安装版用于日常启动；免安装 ZIP 需要完整解压并保留 win-unpacked 目录。单文件便携版每次启动都会自解压，等待时间较长。GitHub 下载包去掉个人酒馆 initial-data、聊天、备份和本地工具状态，以默认配置启动。桌面准备页负责玩家身份，酒馆默认首次命名弹窗关闭，避免隐藏弹窗阻断新用户进入阅读。现有用户数据保存在应用用户目录，新版不会自动清空。

## 模型参数

填写模型 ID，而非目录展示名。max_tokens 上限随接口而异；若服务器返回范围 [1, 98304]，分析输出和截断重试上限均不得超过 98304。建议首次 32768、截断重试 98304。没有修改或自动重试用户任务。

## 验证范围

类型检查、生产构建、模拟模型请求和包内设置页验证通过；没有调用付费或校内模型。旧工程时间地点与历史保留已有离线验收。历史研究测试中部分本地夹具没有随仓库提供，不能宣称完整测试集全部通过。

源码保留内置运行时及第三方许可；个人小说工程、密钥与聊天不在仓库中。
