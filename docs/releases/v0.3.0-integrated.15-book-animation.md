# integrated.15 开书动画修复

在 integrated.15 基础上恢复书库开书动画。点击书封、书籍列表或“打开这本书”后，书籍先聚拢、展开，再显示“进入编译工作台／进入沉浸阅读”选择页。选择页进入编译直接打开，不再等待不可见动画；系统启用“减少动画”时立即显示选择页。

此补丁不改变小说工程格式、已生成资料、人物卡、世界书、模型配置或阅读数据。安装版和解压版沿用应用内部版本号 0.3.0-integrated.15，发布标签用于区分补丁；旧 integrated.15 发布保留。

## 验证

- TypeScript 类型检查及 Vite 生产构建通过。
- 隔离临时书库中，开发版和最终解压包均通过真实桌面测试：书封聚拢与展开、列表入口、返回书库、减少动画、进入编译、TXT 导入、编译导航。
- 未调用模型，未重跑用户小说工程。

## 使用

安装版适合日常使用。解压版请完整解压 ZIP，然后运行 `win-unpacked/小说世界.exe`；不要只单独取出 EXE。
