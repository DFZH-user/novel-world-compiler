# integrated.15 单文件便携版临时目录修复

旧单文件便携版在构建时生成固定 `unpackDirName`。同一文件重复启动时，NSIS 会清理同一个临时目录；先运行的实例因此可能丢失 `icudtl.dat` 和酒馆服务文件，报 `Invalid file descriptor to ICU data received`。这些文件在发布 EXE 中原本存在。安装版和解压版使用稳定目录，不受此问题影响。

本补丁把 `portable.unpackDirName` 设为 `true`。在本项目锁定的 electron-builder 26.15.3 中，这使 NSIS 不定义固定解压目录，转而使用每次启动独立的 `$PLUGINSDIR`。源码附带 `scripts/verify-portable-isolation.ps1`，实际连续启动两份便携实例，核对不同的临时目录和必要资源。此次本机测试通过。

内部应用版本仍为 0.3.0-integrated.15；本次只重建单文件便携附件。酒馆完整安装版和解压版仍可正常使用。本次不修改用户小说工程、数据或模型设置，也不调用模型。
