# 三类基础稿生成台

状态：第八批已实现（三类基础稿 + 可游玩整合包）

规则版本：`artifact-foundation.v1`

数据库：schema v28（基础稿本身不新增平行事实表；v26–v28 仅增加安全试聊、短会话与检索审计）

入口：应用左侧“基础稿生成”，或统一精修台在阻断清零后继续

## 目标

在统一精修的“必须处理”为零后，用同一个已确认事件作为防剧透进入点，生成或重建：

1. 核心/重要人物的 Character Card V2 本地基础草稿；
2. 当前进入位置可见的人物关系图基础快照；
3. 当前进入位置可见的世界地点拓扑基础快照。

三类产物共享进入点，但不共享质量结论。任一产物内容不足，不会把其他两类错误标成失败。

## 为什么不新增“已生成”表

- 角色卡草稿已经持久化在 `character_card_drafts`，继续复用既有人工编辑、审阅和质量报告；
- 关系图和叙事地图是已确认事实在某个进入位置上的纯派生投影，保存第二份图会产生过期副本；
- 图谱和地图每次用现有版本化构建器即时生成，返回稳定 `source_fingerprint`，相同输入可验证为同一基础稿；
- 因此第六批不升级 schema，也不创建第二套产物真相。

## 统一前置条件

- 统一精修台 `readyForArtifactDrafts = true`；
- 进入事件属于当前修订且已经人工确认；
- 角色状态、人物关系揭示和地点揭示全部使用该事件的 `narrative_start_ordinal` 作为防剧透围栏。

未确认事件不会被自动选择。桌面端默认选取当前修订中叙事顺序最晚的已确认事件，用户可以显式更换。

## 三类独立门槛

### 角色卡基础稿

- 目标范围：已确认且分级为 `core / important` 的人物；
- 缺失草稿可以批量补齐；没有已确认事实的人物会失败关闭，不生成无来源角色卡；
- 已有草稿永不被统一生成覆盖；
- 已有草稿的进入事件与本次选择不一致时，明确阻断该角色卡集合，要求到角色卡页人工决定是否重建；
- “基础稿就绪”表示所有目标人物已有同一进入点的草稿；
- “正式导出就绪”仍要求每张卡已人工审阅且通过既有内容质量门槛。

### 人物关系图基础稿

- 只读取当前进入位置已揭示、已正式确认的人物关系及其证据；
- 至少需要一个由正式关系形成的节点；
- 无当前有效关系或存在冲突时给出质量提醒，不伪造边；
- 快照继续使用 `novel-world-character-graph` 1.0 契约与来源指纹；
- 正式 JSON/世界书导出仍在关系图谱页由用户触发。

### 世界地图基础稿

- 只读取当前进入位置已揭示、已确认的地点、空间关系、地点事件和证据；
- 至少需要一个地点节点；
- 没有空间关系时允许形成单节点/多节点拓扑草稿并给出提醒；
- 包含层级冲突显式保留，不自动选择父级；
- 继续坚持 `topology-only`，不会把画布布局伪装成经纬度；
- 正式地图 JSON、地点世界书和 GeoJSON 仍在叙事地图/地点页由用户触发。

## 生成语义

统一按钮执行“可安全生成部分”：

- 只补齐缺失角色卡；
- 已有角色卡原文、人工修改和审阅状态保持不变；
- 即时构建关系图与叙事地图快照，返回节点、关系、事件、证据计数和来源指纹；
- 重复运行时角色卡报告 `skipped`，图谱/地图对相同输入返回相同来源指纹；
- 某张角色卡失败不会阻止两类只读图谱快照生成，失败原因逐项返回。

## 已验证

- 统一精修未就绪时三类产物都显示全局阻断，worker 拒绝生成；
- 正式人物关系和确认地点分别进入各自基础快照；
- 角色卡缺失时可生成，生成后进入“等待精修”，不会冒充正式导出就绪；
- 重复生成不修改已有角色卡内容或更新时间；
- 人物关系图和世界地图对相同输入保持来源指纹一致；
- 更换进入事件后，已有角色卡被识别为进入点不一致且不会自动覆盖；
- 非当前修订或未确认的进入事件被拒绝。

## 第八批：可游玩整合包

- 三类产物必须全部达到正式导出门槛，不能只凭基础稿就绪；
- 每张 Character Card V2 在显式整合包导出时绑定同一份 `data.character_book`；
- 人物关系与地点条目按同一进入段落裁剪，并保留各自来源 ID 和来源种类；
- 包内同时保留两份 SillyTavern 世界书、独立嵌入世界书、进入点元数据和 SHA-256 清单；
- 包目录使用来源指纹寻址，相同输入复用，内容变化生成新目录并保留旧版本；
- 基础稿仍不增加平行事实表。完整契约见 `docs/PLAYABLE-BUNDLE.md`；应用当前 schema 为 v26，新增内容仅是安全试聊审计。
