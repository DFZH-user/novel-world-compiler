# integrated.8 — 可调整 API 请求参数

API 设置新增输出长度、超时、采样、思考模式、兼容模式、批量重试及默认输入分块。
参数保存在本机 API 配置，密钥仍由系统安全存储保护，不进入小说工程。

- 分析输出预算可手填，移除 12,000 Token 固定限制。数值为正整数，最大输入为 2,147,483,647；这是数值校验范围，不是模型能力。服务商的实际模型上限优先。
- 批量人物、事实、事件、关系、地点分析的截断回复按次翻倍，至手动指定的重试上限。上限等于初始预算时不增长。最多尝试 1–10 次，含首次。
- 单次 JSON 生成（例如角色卡）读取全局分析预算，但不增加批量重试流程。
- 编译器角色试聊和改写读取试聊输出预算；不改 SillyTavern 的独立配置。
- 采样留空沿用自动适配或不发送。手动参数在兼容回退中仍保留。JSON 参数关闭不关闭输出数据校验。
- 输入分块以字符计。新工程的一键生成及分析分块表单读取已保存默认值。已有分块不自动重建；已开始任务锁定的分块也不会被设置变更替换。
- 请求超时作用于生成请求；测试连接读取模型列表，不验证生成参数支持情况。
- 老配置按旧默认值加载；更新服务商连接而省略高级参数时保留已有高级参数。
- 默认值按钮只更新表单，安全保存后才持久化。

验证：类型检查，194 项单元测试通过、1 项跳过。模拟传输验证 65,536 Token 不被裁剪、文本预算覆盖旧的 500 Token、600 秒超时、参数持久化和密钥保留。未调用真实付费 API。
