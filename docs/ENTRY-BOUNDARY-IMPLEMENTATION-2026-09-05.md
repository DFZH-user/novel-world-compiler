# 进入点资料过滤：第一阶段实施与验收

日期：2026-09-05。对应路线：`PROJECT-REVIEW-AND-ROADMAP-2026-09-05.md` 中第十一批的第一步。状态：本阶段代码及本地验收完成；不代表完整防剧透系统或人物 Skill 已完成。

## 已实现

- 新增 `StoryKnowledgeProjection`，策略名 `public-entry.v1`。自动卡片资料只使用当前修订、已确认、真值为 asserted、可见性为 public，且在进入段落（含）之前存在已对齐 support 证据的事实。仅有 context 证据不足以提前揭示事实；valid_from 不能提前揭示后期倒叙内容。
- 对白正文及说话人归属的证据段落都必须不晚于进入点；缺少归属证据时保守排除。代表对白和语言画像在过滤后的集合上计算，不再读取全书缓存画像。
- 状态服务增加显式 `public-entry` 模式。进入点之后的事件和不可用的状态变化不能经图路径、候选值或摘要回流。已揭示但因权限无法完整核对的变化，将相关公开旧状态标为不确定，不能把它重新当作恒定现状。
- 卡片生成、模型精修来源、导出前校验复用这一策略。无已知公开事实时明确拒绝生成，不借用未来资料填空。
- 来源摘要增加可选策略版本，指纹覆盖进入点、允许事实的实际内容、允许对白和投影状态。旧版草稿或已变化的投影不能精修、应用旧精修建议或正式导出；批量质量报告明确显示 `stale_knowledge_projection`。
- 不自动重写旧卡片，不改变人工文字及审核记录。用户需要先保留人工修改，再显式重新生成和审阅；本阶段尚未提供自动合并新旧稿的界面。
- 编辑器默认 `editor` 状态查询保留全书信息供作者审核，与自动卡片的公开资料模式明确分离。数据库 schema 仍为 v25，无迁移。

## 回归验证

新增 `tests/integration/character-card-boundary.test.ts`，最初六个用例均在旧实现中失败，实际复现泄漏和失效检查缺失。补充后九个用例全部通过：

1. 正常已知事实仍可用；晚期事实、孤立晚期秘密、倒叙、私密事实和后期对白不进入早期卡片。
2. 精修提示词组装之前已经排除上述原始来源。
3. 移到后期进入点后，后期公开资料恢复可用；编辑器与原始事实没有被删除。
4. 对白出现很早、但说话人仅在后期确认时，不提前归属。
5. 旧版草稿阻止导出/精修，人工文字保留。
6. 进入点发生变化后旧稿失效。
7. 私密新状态被排除时，不把公开旧状态当作确定现状。
8. 事实 ID 未变但可见内容变化时，旧稿仍会失效。
9. 被排除的未来事实变化不使早期卡片无故失效。

原有状态测试仍验证编辑器的私密信息及事件偏序；角色卡快乐路径显式把地点改为公开后再生成，并将旧测试“采样结尾对白”的预期改为不得跨进入点。

桌面完整流程新增两个明确进入事件：过早进入时必须拒绝借用未来人物事实；后续证据已揭示时完成角色卡、批量导出、备份和恢复。另修复一个 UI 冒烟测试依赖真实用户默认模型的问题，改为独立临时配置和显式填写测试模型名，不点击模型调用按钮。

既有 Skill 原型测试的“文本必须含按需”断言改为检查所有引用文件存在且非空。这只验证文件结构；原型的真实 A/B 状态仍是 `not-run`，没有修改其生成服务或更新旧合成验收产物。

## 仍然不能宣称的能力

1. **公开不等于人物知情。** 当前没有按人物记录知情授权或私密对白受众；本阶段仅对事实采用公开白名单，对白采用揭示位置与归属证据过滤。不能将其称为完整人物权限体系。
2. 边界粒度是进入事件的起始段落，包含整个段落，不是句子或字符位置；跨段事件的其他内容不会自动视为已读。
3. 人工编辑的卡片文字、人物规范名称、审核后的事件标题仍须检查剧透；指纹不是对人工文字的语义审查。
4. 世界书、关系/地点导出与 Skill 检索尚未统一接入这个新模块。现有各自的揭示边界仍在，后续需要贯通检查，不能宣称整合包所有内容已具备相同知情规则。
5. 时间有效区间、倒叙和部分有序事件仍依赖已有审核关系；本阶段修复“何时揭示”的资料入口，不补齐所有“何时有效”的语义。精修资料中的历史事实仍需与进入状态区分。
6. 合成回归不能证明真实小说的抽取准确率、人物可玩性、泄漏概率或模型成本。

## 下一接续点

先将相同边界贯通到关系/地点世界书及导出元数据，提供可解释的排除原因，并处理人物名称、事件标题与知情授权的资料缺口；同时准备不调用付费模型的真实样本标注清单。之后再选择一个核心人物和一个进入点交付最小场景包，再开展公平的原生世界书/检索对照。
